Layer-StudioWerkzeuge als Layer kombinieren — Export als .lac

Layer
Noch keine Layer. Oben hinzufügen, dann auf der Fläche ziehen (Skalieren/Drehen an den Griffen).
Ausgewählter Layer
Eckgriffe = skalieren (gegenüberliegende Ecke bleibt fix; Alt/Cmd = um die Mitte). Kreis oben = drehen (Shift = 15°).
Arbeitsfläche
Einrasten (Snapping)
Rastet an Build-Plate, A4-Blatt und anderen Layern ein (Kanten + Mitte). Shift gedrückt halten = Snapping vorübergehend aus.
Export
Alle sichtbaren Layer werden als benannte Objekte in eine .lac gepackt (Prozess: Stift zeichnen).
Projekt
Speichert das Layout als .handschrift-Datei (Layer, Position, Parameter und Striche). Zum Weitermachen oder Weitergeben.
